# Documentation Rules

## Structure

### ClassesAndSystems/
Contains detailed documentation for each class and system:
- Full class structure description
- All methods and properties
- Usage examples
- Implementation details

### Project documentation.md
Contains high-level overview:
- Brief description of class purpose
- Key functionality summary
- Link to detailed documentation in ClassesAndSystems/

## Format

When documenting a class:
1. Create detailed file in `docs/ClassesAndSystems/ClassName.md`
2. Add brief overview in `docs/Project documentation.md` with link to detailed file

## Language

All code comments and XML documentation summaries must be written in English.
